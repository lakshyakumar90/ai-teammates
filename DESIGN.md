# Public landing page

This direction applies to the public `/` page. The existing application UI retains its current theme and components.

The user supplied Skydive as the visual reference. Firecrawl's captured screenshot, HTML, and branding are saved locally under `.firecrawl/skydive-reference.*` (ignored research artifacts).

Use a warm off-white canvas, near-black typography, pill-shaped navigation and calls to action, generous whitespace, and a central headline encircled by pastel portrait tiles. Use the app's existing DiceBear avatars rather than Skydive's character images. Geist is the existing, available font.

Lower sections demonstrate the actual group conversation, memory scopes, and individual computer features. Demonstration conversations are labeled as examples. Navigation uses real section anchors; conversion links lead to authentication or the dashboard. Motion is restrained and disabled for reduced-motion preferences. Mobile collapses the navigation links and simplifies the portrait arrangement.
